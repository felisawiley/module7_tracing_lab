What does NZP mean?

Negative, Zero or Positive: the condition codes used by branches. Arithmetic operations update NZP based on their result. CMP/CMPI set NZP from a comparison, without changing general registers.

Quick reference

CONST Rd, #imm
Load an immediate constant into a register.
ADD Rd, Rs, Rt
Add two registers.
ADD Rd, Rs, #imm
Add a small immediate constant.
CMPI Rs, #imm
Set NZP by comparing a register to an immediate.
BRp / BRz / BRnz / BRnzp
Branch if the selected condition code matches.
JMP LABEL
Jump to a labeled instruction (assembler resolves address).
SLL
Shift a register value left.
