What does NZP mean?

Negative, Zero or Positive: the condition codes used by branches. Arithmetic operations update NZP based on their result. CMP/CMPI set NZP from a comparison, without changing general registers.

Remember

CMP / CMPI update NZP, not the general-purpose registers. The following BR decides whether to change control flow using those condition codes. A compare itself advances to the next instruction.

Why sign extension matters

Immediate values in instructions use fewer than 16 bits. To use them in 16-bit operations, the processor sign-extends them: it copies the most significant bit (the sign bit) into all the higher positions.

Example: A 5-bit value of 11111 (−1 in decimal) becomes 1111111111111111 (still −1 as a 16-bit value). This preserves the negative value correctly.

How the three shifts differ

SLL moves bits left and fills new right-hand positions with 0. SRL moves bits right and fills new left-hand positions with 0. SRA moves bits right while copying the original sign bit into the new left-hand positions.

Note: LC-4 sets NZP from the full 16-bit instruction result. The NZP display above describes the 8-bit teaching result, not a simulated 16-bit LC-4 register.
